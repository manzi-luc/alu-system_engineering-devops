# SSH

This directory contains scripts for connecting to a remote server with SSH keys.

## Files

| File | Description |
|------|-------------|
| `0-use_a_private_key` | Bash script that connects to my server as `ubuntu` using the private key `~/.ssh/school` |

## Usage

```bash
./0-use_a_private_key
```

## Notes

- Private keys are never stored in this repository.
- The script must be executable: `chmod +x 0-use_a_private_key`.
