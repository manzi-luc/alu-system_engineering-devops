Scripts and exercises for the system engineering and DevOps projects.

## Directories

| Directory | Description |
|-----------|-------------|
| `ssh` | Scripts for connecting to a remote server with SSH keys |

## ssh

| File | Description |
|------|-------------|
| `0-use_a_private_key` | Bash script that connects to my server as `ubuntu` using the private key `~/.ssh/school` |

## Notes

- Private keys are never stored in this repository.
- Scripts must be executable: `chmod +x <file>`.
